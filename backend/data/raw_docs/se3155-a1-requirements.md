Course: Software Engineering 3155
Term: Fall 2026
Scope: Assignment 1: Interactive Ham Sandwich Maker Machine
Content type: assignment_requirements
Confidence: verified
Keywords: Assignment 1, requirements, must, implementation

Requirements: 1) The user selects a sandwich size. 2) The program checks available resources before production. 3) If resources are insufficient, the program reports the shortage and does not make the sandwich. 4) If resources are sufficient, the program accepts coins and compares the inserted amount with the cost. 5) The program reports insufficient payment or returns the applicable change. 6) The user can request a remaining-resource report and turn off the machine. 7) Complete the supplied skeleton in PyCharm and submit main.py.
