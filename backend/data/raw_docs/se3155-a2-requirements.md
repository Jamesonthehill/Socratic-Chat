Course: Software Engineering 3155
Term: Fall 2026
Scope: Assignment 2: Modular Ham Sandwich Maker Machine
Content type: assignment_requirements
Confidence: verified

Requirements: 1) Use four files: main.py, data.py, sandwich_maker.py, and cashier.py. 2) Import data, sandwich_maker, and cashier at the top of main.py. 3) Create variables from the resources and recipes dictionaries in data.py. 4) Create instances of SandwichMaker and Cashier; SandwichMaker receives resources through its constructor. 5) Move check_resources and make_sandwich into SandwichMaker. 6) Move process_coins and transaction_result into Cashier. 7) Keep recipes and resources in data.py as temporary in-memory data. 8) Use main.py as the program entry point and integration layer.
