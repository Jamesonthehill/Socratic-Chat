# Course AI-use policy

Course: Software Engineering 3155
Term: Fall 2026
Scope: Course-wide
Content type: academic_integrity_policy
Confidence: verified
Keywords: ChatGPT, Copilot, quiz, debugging, code generation

Course AI-use policy: 1) Students may not use ChatGPT, GitHub Copilot, or similar AI tools for quizzes. 2) Students may not use ChatGPT or similar AI tools to generate coding-assignment code from scratch. 3) For coding assignments, students may use an AI chatbot to debug code they have written. 4) This chatbot must therefore require the learner to provide their own attempt, reasoning, or error before offering code-level debugging guidance.
